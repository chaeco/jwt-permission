为什么是 JWT Permission

权限与认证，各司其职。

token 验证交给上游 JWT 中间件，本库只做一件事：这条路由到底要不要放行。

⇄

Auto-Discovery

与 @chaeco/auto-router 联动，从 app.$routes 自动读取权限元数据。

app.use(jwtAuth({ autoDiscovery: true }))
// 无需手动维护路由列表
?

defaultDeny 生产模式

未知路由默认放行；defaultDeny: true 时改为 401——推荐生产环境开启。

jwtAuth({
  defaultDeny: true,
  onUnauthorized: (ctx, reason) => audit(reason),
})
!

URL 解码安全

路径参数匹配 + URL 解码防护，阻止 %xx 编码绕过攻击。

{ method: 'GET', path: '/api/users/:userId' }
// 匹配 /api/users/123

配置模式

三种姿势，适配任意框架。

自动发现、手动路由列表、自定义匹配函数——按需选择。

选项类型默认说明
autoDiscoverybooleantrue从 app.$routes 自动发现
publicRoutesRouteRule[]—跳过 JWT 验证的路由
protectedRoutesRouteRule[]—需要 JWT 验证的路由
defaultDenybooleanfalse未知路由返回 401（生产推荐）
onUnauthorized(ctx, reason) => void—拒绝审计钩子：'no_user' / 'default_deny'
isPublicRoute / isProtectedRoute(method, path) => boolean—自定义匹配函数（覆盖内置）

用法

两行接入，按框架配置。

Hoa / Koa / Express 各有对应桥接方式。

import { Hoa } from 'hoa';
import { jwt } from '@hoajs/jwt';
import { jwtAuth } from '@chaeco/jwt-permission';

const app = new Hoa();

app.use(jwt({ secret: process.env.JWT_SECRET!, algorithms: ['HS256'] }));
app.use(jwtAuth({ autoDiscovery: true }));
app.extend(autoRouter({ defaultRequiresAuth: false }));

app.listen(3000);
import Koa from 'koa';
import koaJwt from 'koa-jwt';
import { jwtAuth } from '@chaeco/jwt-permission';

const app = new Koa();

app.use(koaJwt({ secret: process.env.JWT_SECRET! }));
app.use(jwtAuth({
  publicRoutes: [{ method: 'POST', path: '/api/auth/login' }],
  protectedRoutes: [{ method: 'GET', path: '/api/profile' }],
}));

app.listen(3000);
import express from 'express';
import { expressjwt } from 'express-jwt';
import { jwtAuth } from '@chaeco/jwt-permission';

const app = express();

// 桥接：req.auth → ctx.state.user
app.use((req, res, next) => {
  expressjwt({ secret: process.env.JWT_SECRET!, algorithms: ['HS256'] })(req, res, () => {
    (req as any).state = { user: (req as any).auth };
    next();
  });
});

// Express 需要自定义 unauthorizedResponse
app.use(jwtAuth({
  publicRoutes: [{ method: 'POST', path: '/api/auth/login' }],
  unauthorizedResponse: ctx => {
    (ctx as any).res.status(401).json({ code: 'UNAUTHORIZED' });
  },
}));

请求流

一条请求，三步判定。

JWT 解析 → 路由注册 → 权限检查，顺序不可颠倒。

1

JWT 解析中间件

验证签名与过期时间，把解码后的 payload 写入 ctx.state.user。

app.use(jwt({ secret, algorithms: ['HS256'] }))
2

autoRouter 注册

扫描控制器目录，收集 requiresAuth 元数据，存入 app.$routes。

app.extend(autoRouter({ dir: './controllers' }))
3

jwtAuth 判定

公开路由放行 → 受保护路由检查 user → 未知路由按 defaultDeny 决定。

app.use(jwtAuth({ autoDiscovery: true }))
